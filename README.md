## README - Clone Discord Interface

## 📋 Sobre o Projeto  
Clone da página institucional do Discord desenvolvido com **HTML5 e CSS3 puro**, com foco em **layout responsivo**, organização de seções e boas práticas de estruturação semântica.  
Projeto criado como prática de **Flexbox, Media Queries e adaptação de layouts mobile-first**.

---

## 🚀 Tecnologias  
- HTML5 – Estrutura semântica  
- CSS3 – Layout e estilização  
- Flexbox  
- Media Queries  
- Google Fonts (Luckiest Guy e Open Sans)

## 🎨 Funcionalidades  
✅ Header com imagem de fundo e chamada principal  
✅ Botões de ação estilizados  
✅ Seções com layout alternado (texto + imagem)  
✅ Fundos intercalados para separação visual  
✅ Imagens responsivas sem quebra de layout  
✅ Layout adaptável para mobile e desktop  

---

## 🖥️ Como Usar  
Clone o repositório  
Abra o arquivo `index.html` no navegador  
Ou utilize o **Live Server** no VS Code:  
Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.

---

## 📸 Layout  
Mobile-first  
Breakpoints a partir de 700px  
Containers centralizados com `max-width`  
Imagens com `max-width: 100%` e `height: auto`  
Seções com fundo que acompanham o crescimento do conteúdo  

---

## 🎯 Conceitos Aplicados  
Flexbox para alinhamento de conteúdo  
Separação entre seção de fundo e container interno  
Responsividade sem uso de alturas fixas  
Boas práticas de organização de CSS  
Uso correto de imagens responsivas
